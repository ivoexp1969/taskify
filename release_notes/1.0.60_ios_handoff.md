## 1. Синхронизирай repo-то
```bash
cd ~/taskify        # пътят до клонирания repo на Mac
git pull --rebase origin main
```
Дърпа 1.0.60+70 + analytics изравняването + review_service тунинга + генерираните
Play скрийншоти (`store_metadata/play/screenshots_generated/`) + новите tools
(`play_listing.py`, `play_screenshots.py`).

## 2. Dependencies + Pods
```bash
flutter pub get
cd ios
pod install          # Podfile.lock: purchases_flutter 10.8.0 → трябва да мине чисто
cd ..
```
**Ако `pod install` гръмне** (рядко):
```bash
cd ios && pod repo update && pod install && cd ..
```

## 3. Версия/билд номер (виж ⚠️ горе)
Отвори `ios/Runner.xcworkspace` → таргет **Runner** → General → Version/Build.
Ако сменяш номера — подай го на билда (`--build-number=71`) или редактирай в Xcode.
Deployment target е **iOS 14.0** (`ios/Podfile`) — не сваляй.

## 4. Билд + качване
**Вариант А (CLI):**
```bash
flutter build ipa --release            # или с --build-number=71 (виж ⚠️)
```
После качи `build/ios/ipa/*.ipa` през **Transporter** или Xcode Organizer.

**Вариант Б (Xcode, по-надежден за signing):**
`ios/Runner.xcworkspace` → **Any iOS Device** → Product → **Archive** → Organizer →
**Distribute App** → App Store Connect → Upload.

### ⚠️ Signing капан (проверено на предишни билдове)
Ако гръмне `Command CodeSign failed` / `errSecInternalComponent`: keychain-ът
`habits-ci` (от app „Навици") е в codesign search list-а със счупени копия на
Taskify сертификатите. Фикс:
```bash
security list-keychains -d user -s ~/Library/Keychains/login.keychain-db
rm -rf ~/Library/Developer/Xcode/DerivedData/Runner-*
```
Ако `xcode-select` сочи несъществуващ Xcode:
```bash
sudo xcode-select --switch /Applications/Xcode.app
```
⚠️ Върни `habits-ci` в search list-а, когато билдваш „Навици".

## 6. Скрийншоти (App Store)
- Генерираните брандирани кадри в repo-то са за **Google Play** (телефон, **1080×1920**,
  9:16): `store_metadata/play/screenshots_generated/{en,bg}/01..04.png` — от
  `tools/play_screenshots.py`. **НЕ пасват директно на App Store размерите.**
- App Store иска други резолюции: **6.9"/6.7"** (1290×2796 или 1284×2778) и по избор
  6.5"/5.5". Опции:
  1. Пре-генерирай за iOS: суровите кадри са в
     `C:\Users\Admin\Desktop\task_manager 10012026 GOOGLEPLAY\Screenshots 18092026`
     (Android capture 1080×2220); за iPhone направи нови captures от iOS Simulator
     (`xcrun simctl io booted screenshot shot.png`) в изисквания размер, после
     разшири `play_screenshots.py` с iOS платно.
  2. Или качи в App Store Connect текущите скрийншоти на съществуващата 1.0.5x listing,
     ако вече са одобрени (App Store пази скрийншотите между версии — не е нужно да ги
     сменяш всеки билд).
- Надписите (двуцветни, ключова дума в зелено `#2CD4A0`) са същите за двете платформи —
  само платното/резолюцията се различава.
