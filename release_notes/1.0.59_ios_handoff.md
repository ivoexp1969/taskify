# iOS билд handoff — v1.0.59(69) → App Store (на Mac)

> Създадено от PC на 2026-09-13. Версията вече е `1.0.59+69` в `pubspec.yaml` (важи и за двете платформи).
> Android е тестван на живо (Note 9, без краш), но **НЕ е качен в Play още** (живо остава 1.0.58+68).
> Промените в 1.0.59 са **чист Dart без нови native deps** (разписанието = SharedPreferences;
> `PrefsSyncService` ползва вече наличния `cloud_firestore`) → iOS билдът е стандартен.

## 1. Синхронизирай repo-то
```bash
cd ~/taskify        # пътят до клонирания repo на Mac
git pull --rebase origin main
```
Дърпа 1.0.59+69 + студентското разписание v2 + `PrefsSyncService` (cross-device sync на разписание/профил)
+ „Какво ново" диалога.

## 2. Dependencies + Pods
```bash
flutter pub get
cd ios
pod install          # Podfile.lock вече е на purchases_flutter 10.8.0 → трябва да мине чисто
cd ..
```
**Ако `pod install` даде конфликт** (рядко, при остаряло local repo):
```bash
cd ios && pod repo update && pod install && cd ..
```

## 3. Провери версията
Отвори `ios/Runner.xcworkspace` в Xcode → таргет **Runner** → General → трябва да е **Version 1.0.59, Build 69**
(чете се от pubspec). Ако не — `flutter clean && flutter pub get`.

## 4. Билд + качване
**Вариант А (CLI):**
```bash
flutter build ipa --release
```
После качи `build/ios/ipa/*.ipa` през **Transporter** или Xcode Organizer.

**Вариант Б (Xcode, по-надежден за signing):**
Xcode → `ios/Runner.xcworkspace` → **Any iOS Device** → Product → **Archive** → Organizer →
**Distribute App** → App Store Connect → Upload.
